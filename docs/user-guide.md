# Guide utilisateur

## Démarrage rapide

1. **Lancer** : `./LANCER_EONORA.command` ou ouvrir l'app Eonora Tech OS
2. **Première connexion** : Si c'est la première fois, définir un mot de passe
3. **Tableau de bord** : Vue d'ensemble — agenda, santé financière, projets

---

## Modules principaux

### Tableau de bord

- **Agenda** : Timeline du jour, événements. Connexion Google Calendar facultative.
- **Santé financière** : Bénéfice net, entrées/sorties, barre "Yacht".
- **Projets** : Cartes clients avec statut, progression, prochaine action.
- **Filtres** : Actif, Archivé, Prospect, Perso, Pro Bono, Tous.

### Fiche client

- **Workflow** : Phases du projet (Exploration → Cartographie → Magie Visuelle → Construction → Polissage → Jardinage).
- **Onglets** : Tâches & Objectifs (Kanban), Temps, Finances, Fichiers & Liens, E-mails, Portail.
- **Sidebar** : Identité visuelle, Profil client, Maintenance, Brand Center, Coffre-fort.

### Tâches (Kanban)

- Colonnes : À faire, En cours, Terminé.
- Drag & drop entre colonnes.
- Priorité : Low, Medium, High.
- Phase assignée par tâche.

### Finances

- Factures : Création, export PDF, QR code suisse.
- Dépenses : Scanner factures, catégories.
- Notes : Notes rapides liées au workspace.
- Time tracking : Temps loggé par projet.

### Emails

- Connexion Infomaniak (IMAP/SMTP).
- Envoi, réception, pièces jointes.
- Classement par dossier, recherche.
- IA : Réponse et résumé automatiques.

### Portail client

- **Côté Marion** : Publier livrables (liens, images, fichiers), updates, consulter commentaires et fichiers envoyés par le client.
- **Côté client** : Accès via lien partagé + PIN. Consultation, commentaires, envoi de fichiers.

### Franck (IA)

- Chat contextuel : Analyse des projets, suggestions.
- Mode Focus : Coach Franck pour la concentration.
- Briefing : Génération de briefs.
- Outils : QR code, logo, suppression arrière-plan, palette couleurs, etc.

### Mode Focus

- Écran minimaliste pour la concentration.
- Sons d'ambiance (Pluie, etc.).
- Coach Franck : Chat coaching intégré.

---

## Paramètres

- **Profil** : Nom, email.
- **IA** : Clé API Gemini.
- **Google** : Connexion OAuth (Calendar, Drive).
- **Email** : Comptes Infomaniak.
- **Apparence** : Thème (clair, sombre, licorne).
