Bienvenue à Bord

Guide d'installation de ton Assistant CRM
1

Télécharger le projet

Depuis la page GitHub, clique sur le bouton vert <> Code puis choisis Download ZIP.

⚠️ Important : Décompresse le dossier ZIP directement sur ton Bureau (Desktop).
2

Lancer l'installation

Ouvre le dossier, fais un clic droit sur le fichier INSTALLER.command et choisis Ouvrir.

(Si une alerte de sécurité apparaît, confirme simplement en cliquant sur "Ouvrir").

3

Activer "Franck" (L'IA)

À la fin de l'installation, on te demandera une Clé API. C'est gratuit et ça prend 1 minute :

Obtenir ma clé API Google ✨

Connecte-toi avec ton compte Google, clique sur Create API key, et copie la clé (elle commence par AIza...).

Colle-la ensuite dans la fenêtre noire d'installation et appuie sur Entrée.

C'est terminé ! 🚀

Pour lancer ton app, double-clique simplement sur :
